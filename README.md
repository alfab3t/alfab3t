<p align="justify">
  Halo! Saya <b>Djohan Baw</b>, mahasiswa <b>Manajemen Informatika di Politeknik Astra</b> yang berfokus pada <b>Software Engineering, Web Architecture, dan Cross-Platform Native Development</b>. Saya berpengalaman membangun solusi perangkat lunak multi-platform—mulai dari sistem enterprise berbasis web, backend bervolume tinggi, hingga aplikasi mobile cerdas untuk monitoring IoT dan tanggap darurat K3/HSE.

</p>
